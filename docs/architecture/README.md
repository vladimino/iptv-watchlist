This is the maintained architecture navigation for thirteen pages. Diagrams describe confirmed current behavior and explicitly label future migration boundaries; they do not authorize production operations. The accepted AIR-323 Discovery Workflow diagrams ([ADR 0083](../adr/0083-inert-discovery-workflow.md)) received owner visual approval on 2 November 2026, as did the Film/Person owner-name and marker diagrams at their recorded gates. The proposed Letterboxd confirmed-apply sequence remains a separate gate. **Four AIR-319 current-state diagram edits** on the EPG, runtime-topology, persistence and scheduling pages still require a fresh rendered owner visual approval before PR #339 is merged. The ratings-sequence note and the dashed ratings arrow ([ADR 0084](../adr/0084-d1-authoritative-ratings.md), Accepted) were visually approved on 2026-11-04 while the marker was `r2`. Activation at 2026-11-04 08:02 UTC set the marker to `d1` / `open`. The sequence now draws a D1 participant for history, facts, the cursor, the removal queue and the run record, and keeps event arrows on R2. Both rendered diagrams need a fresh owner visual approval.

For decisions read the [ADR register](../adr/README.md); for maintained implementation contracts see [reference](../reference/README.md); for operations see [runbooks](../runbooks/README.md); for bounded historical measurements see [evidence](../evidence/README.md).

## Boundary and reading rules

- **Current production:** Cloudflare Worker `iptv` with R2 and D1 domain-specific authority. The legacy ChatGPT Site is a reserve; it is not a second current source.
- **Current storage authority (4 November 2026):** Production D1 schema v11 ([discovery apply](../evidence/d1-migration/air-320-discovery-apply-2026-11-04.md)). Metadata cache, mutable predictions, published EPG/watchlist generation, owner reviews, ratings and discovery are separate D1-authoritative domains. The published-EPG marker is `mode=d1`, `cutover=open`, as shown by the operator's [AIR-319 cutover evidence](../evidence/d1-migration/air-319-production-cutover-2026-11-03.md). R2 remains authoritative for Films and Persons; published JSON/pointer objects are mirrors. Ratings documents are D1. The owner-review marker is `d1` at generation 1 ([activation record](../evidence/d1-migration/air-314-owner-review-activate-2026-11-03.md)). A separate activation at 2026-11-04 08:02 UTC set the ratings marker to `d1` / `open` at generation 1, with 475 documents and 891 view rows ([activation record](../evidence/d1-migration/air-318-ratings-activate-2026-11-04.md)). A manual MCP run at 08:28 UTC left generation 12 ([manual run](../evidence/d1-migration/air-318-ratings-manual-run-2026-11-04.md)). Those writers use D1 and do not fall back to R2 ([ADR 0084](../adr/0084-d1-authoritative-ratings.md), Accepted). Discovery activation at 22:27 UTC set `discovery_authority` to `d1` / `open` at generation 1, with 36999 observations ([activation record](../evidence/d1-migration/air-320-discovery-activate-2026-11-04.md)). A daily-task-created run first published a post-cutover generation successfully after one separately authorized manual step on 3 November; unattended completion remains unverified; direct D1/R2 parity for generation 2 passed on 3 November (see [AIR-319 evidence](../evidence/d1-migration/air-319-production-cutover-2026-11-03.md)).
- **Operational independence:** GitHub deployment, external ChatGPT Scheduled Tasks, MCP invocation, and R2 writes are separate actions. No diagram grants approval for live operations.
- **Plans versus facts:** proposed diagrams must show observed/current paths distinctly from future migration paths, citing supporting reference/ADR documents. No guessed alternatives or invented topology.

## Authoring checklist for future tasks

Each page should identify the authoritative code/ref at review time; label deployed versus planned transitions; explain data ownership, trust boundaries, retry/error paths and rollback implications where relevant; and link the source ADR and maintained reference. When Mermaid is added, check rendering in GitHub and confirm arrows do not imply a non-existent D1 writer, internal credential-forwarding hop or autonomous discovery recursion.

Future changes to the depicted architecture must revise the relevant pages along with implementation and ADRs. [Contributor and agent instructions](../../AGENTS.md) provide the required review and safety rules; the root README is a separate navigation entrypoint.
