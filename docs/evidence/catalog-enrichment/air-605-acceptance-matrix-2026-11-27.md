# Catalog Enrichment Producer: ADR 0219 acceptance matrix for AIR-605, 27 Nov 2026

**What this is.** A map from each planned acceptance group of [ADR 0219](../../adr/0219-discovery-film-enrichment-and-refresh.md) to the executable test that covers it in AIR-605, and an explicit list of what is **not** covered here. All tests run offline on the migrated schema (sqlite3 CLI D1 stand-in) with injected upstreams; none touches production. A listed test is a statement about the code at the PR head, not about production behavior.

| ADR 0219 group | Covered by | Not covered in AIR-605 |
| --- | --- | --- |
| Signal contract: normalized key, coalescing, version token, identical digest wakes nothing, rolled-back change writes none | `migration-0047-catalog-enrichment` sections 2 to 5; `catalog-enrichment-store` (emit) | Emitters that belong to other cards: Discovery (AIR-684), Watchlist (AIR-615), PV1 triggers (AIR-631) |
| Guarded consumption: re-arm during consumption, stale effect, scope, control, lease or identity moved, replay writes nothing | `catalog-enrichment-store` (guarded consumption including a moved or conflicting claim and a redirect, a stale failure never backing off a fresher version, eligibility before the window); `catalog-enrichment-producer` (state rows fenced by identity and plan epoch, a merge during a plan); `catalog-enrichment-wake` and `canonical-repository` (a merge or retirement moves the membership in the same batch) | |
| Wake races: commit then kick, park intent then re-check, kick during handover, lost kick recovered by reconcile, due `retry_at` wakes without cron | `catalog-enrichment-wake` (causal postcommit kick: dormant, runnable, none, failing, rolled back, an uncertain outcome, the real rated admission writer, a merge); `catalog-enrichment-workflow` (kick, reconcile, park cancelled by late work, handover successor); `catalog-enrichment-drain` (park until earliest retry, backed-off signal due time) | Platform behavior of `sendEvent` and `waitForEvent` (injected in tests) |
