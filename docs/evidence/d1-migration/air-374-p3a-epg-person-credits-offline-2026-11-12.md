Design: [ADR 0126](../../adr/0126-epg-producer-layer-person-credits.md).

**Result:** the pure planning and apply layer for `person_state` and `film_credits` units of an EPG run exists and is DORMANT: nothing calls it, `build.mjs` is unchanged, `epgSync` is unchanged, no operation is registered and no marker moves. `handoffReadiness` is unchanged: `producer_not_wired:epg_commit` stays a blocker. The draft differential exceptions are neither accepted nor edited. Every canonical write goes through `recordPersonState` or `mutateFilm` with the receipt tail; the new modules hold no write SQL (a static test checks it).
