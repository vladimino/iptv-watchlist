Files apply in order; `0001` is never rewritten. Production D1 `iptv` carries `0001`–`0006` (schema v6). The repository also contains `0007`, which is not applied. The metadata cache marker is `d1`. Films, Persons, EPG, predictions, ratings and the other domains are not D1-authoritative. The Worker is bound to the database and reads none of these files. Applying a migration to `iptv` is a separate, action-specific owner approval ([backfill runbook](../docs/runbooks/d1-backfill.md)). There is no second database to migrate. For `0005`, that approval also covered the live sync-clock writes, because the projector flag was already `on`. For `0006`, applying the file left the marker at `r2`; the later `--activate` set it to `d1`. The contract is the [D1 reference](../docs/reference/data/d1-schema.md).
