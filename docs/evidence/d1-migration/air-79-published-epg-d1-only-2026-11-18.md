## Behaviour change for the Worker

A Worker whose database carries the published tables with a marker not at `d1` / `open`, or whose database has no published tables, now answers the programme, watchlist, catalog and Admin reads with `published_epg_unavailable` (the existing `502`/`503` mapping of that code) instead of serving the R2 pointer. Production is unaffected: the marker is `d1` / `open` and `wrangler.jsonc` sets no stand-in. Local development (`scripts/local-dev.mjs`) has no D1 binding and keeps its explicit stand-in.

## Tests

`tests/published-epg.mjs` keeps every publication, fence, claim, resume, wide-row, mirror and completed-read case and replaces the import/activate/seal/release/revert block with the refusal of a held cutover and of a marker in mode `r2` by `currentGeneration`, `readAuthority`, `repairMirrors`, `writeMirrors`, `saveWatchlist` and `publishGeneration`, with no mirror put. `tests/epg-mirror-reconciliation.mjs` expects the refusal for a held marker instead of `reason: 'held'`. `tests/published-epg-completed.mjs` drops the revert guard. `tests/published-epg-production.mjs` proves every retired command is refused before any request (with and without confirm and drain flags) and keeps status and the schema apply. The shared projector loader (`tests/d1-enrichment-context.mjs`) gains an explicit `publishedEpgStandin` option (default on), like the owner-review and metadata-cache ones: the loader, not the production module, answers as an uninstalled domain when the module refuses and the database has no published table at all, for the projector fixtures that serve the R2 generation; `tests/tmdb-tv-runtime.mjs` and `tests/local-api.mjs` use schemas below 8 with the explicit flag, and `tests/owner-review-d1.mjs` publishes through the D1 publisher, and It also proves the stand-in serves only an absent domain: with the opt-in, a database with no tables (no `schema_contract`, a contract table without its row, a contract at 7) stands in, a contract at 8, 23 or 24 with zero tables is refused with no mirror write (it fails against the previous head), while one `published_epg_*` table with no `schema_contract`, no `id=1` row, a non-numeric version or a contract below 8 is refused by the reader, `currentGeneration`, `repairMirrors` and `writeMirrors` with no mirror write (it fails against the first head). `tests/prediction-domain.mjs` proves the strict loader refuses a database without them and a marker in mode `r2`.
