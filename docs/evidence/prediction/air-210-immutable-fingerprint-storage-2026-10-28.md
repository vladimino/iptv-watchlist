- **Card:** [AIR-210](https://trello.com/c/DM1Rrnrz). **Captured:** 28 October 2026, 17:01–17:03 UTC. **Code:** GitHub `main` at `a149842`; the objects were written by the Worker version live at 16:24–16:27 UTC (wrangler deployment of PR #205, `6cdaf430…`, 16:05 UTC); the writer code (`writeFingerprint`, `putCreateOnly`, `generationRecordAcceptable` in `src/enrichment.js`) is unchanged between that deployment and `a149842`.
- **Scope:** stage A acceptance of [ADR-0035](../../adr/0035-selective-fingerprint-transition-compatibility.md) section 2 storage after `FINGERPRINT_VERSION_OBJECTS=on`, plus the stage B parity of `PREDICTION_FINGERPRINT_COMPATIBILITY=selective` on the same snapshot. Three films whose fingerprint was generated by the ordinary hourly Scheduled Task run `a9a11f05-a7da-4ab1-84c2-320ba0a20049` (16:22–16:44 UTC): `tmdb_408266`, `tmdb_440471`, `tmdb_1262690`.
- **Method:** read-only only. Cloudflare API R2 `GET` and `LIST` on bucket `iptv` and `GET` of the Worker deployments (owner session); IPTV MCP `prediction_film_diagnostics`, `prediction_queue_overview`, `enrichment_queue`. No `PUT`, `POST`, flag, Task, model, sync, discovery, retry, lease, export or snapshot. Fingerprint contents are not reproduced here; only keys, sizes, timestamps and hashes.
- **Verdict:** **PASS** for all three films and for the snapshot invariants. GO to close AIR-210.
- **Lifecycle / Used by:** closes the stage A storage gate recorded on the card (13:24 UTC comment). **Superseded by:** none.
- **Operational authority:** none.
