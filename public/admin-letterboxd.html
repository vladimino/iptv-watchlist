Архив Letterboxd

Один шаг за раз. Сначала проверка экспорта Letterboxd, и только отдельным шагом запись одной партии. Архив разбирается на сервере в рамках запроса и нигде не сохраняется. Время на экране — Europe/Madrid. Поле UTC нужно только если файл переименовали.

Проверить архив

Letterboxd → Settings → Data → Export your data. Обычное имя: letterboxd-<имя>-ГГГГ-ММ-ДД-ЧЧ-ММ-utc.zip. Не больше 10 МБ.

Только для переименованного файла: у обычного имени время читается из имени, а на экране показывается по Мадриду. Поле UTC оставь пустым, если файл не переименовывали.

Сервер проверяет архив и сравнивает его с R2…

∅Архив ещё не проверялсяВыбери файл и нажми «Проверить архив». Результат живёт только в этой вкладке до очистки или ухода со страницы.
