## Uncertainty

A single conditional request cannot tell a real write between the listing and the `HEAD` from a systematic mismatch between the listed ETag and R2's conditional `HEAD` handling. No further request was sent to tell them apart, because only one export was approved. If the cause is systematic, a repeat in a quieter window fails the same way. Two inputs separate the cases: whether a Scheduled Task or enrichment run was active around 20:11 UTC, or, with separate approval, one unconditional `HeadObject` of that key compared with the start of the run.
