# AIR-537 slice 3: dormant D1 enrichment projector retired, 19 November 2026

**Trello:** [AIR-537](https://trello.com/c/wbe7jjNs). **Basis:** [AIR-79 final retirement audit](air-79-final-retirement-audit-2026-11-18.md), scope item 3; earlier slices: [1](air-537-discovery-installer-retirement-2026-11-18.md), [2](air-537-film-person-operator-tooling-retirement-2026-11-18.md). **Captured:** 19 November 2026 (UTC) on `main` `9b7476d`. Static code and documentation change; no production read or write, no run of any projector, seed or sync.

## Method and what the callgraph proved

Import and symbol graph over `src/`, `scripts/`, `tests/`, `build.mjs`, the test registries and the maintained docs, on the exact `main` above, not taken from the AIR-79 audit. Findings:

- `runD1EnrichmentProjection` has **no production caller**: the Worker cron does not call it ([ADR 0155](../../adr/0155-retire-enrichment-projector-cron.md)), no MCP tool, route, Workflow or Scheduled Task does, and `tests/cron-schedule-simulation.mjs` and `tests/epg-orchestration.mjs` assert the tick does not name it. In the Worker it returned `retired` before any lease, window, R2 read or D1 write because `d1EnrichmentMode` is `null` unless the offline global `D1_ENRICHMENT_TEST_HARNESS` is set, which production never sets.
- Of the 66 top-level symbols of `src/d1-enrichment.js`, exactly one has a production consumer: `d1EnrichmentStatus` (read by `src/catalog-d1.js` for `/api/d1/status`). The other 65 belong to the runner chain and were consumed only by tests and bench scripts.
- `D1_ENRICHMENT_TEST_HARNESS` had no consumer other than the runner's tests.
- Besides the bundled module, three further consumers were found through the shared test loader (`tests/d1-enrichment-context.mjs`): `prediction-domain`, `published-epg` and `d1-projection-seed`; they used the runner for scenarios and the status for assertions.
