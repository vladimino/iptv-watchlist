# Catalog Enrichment Producer: ADR 0219 acceptance matrix for AIR-605, 27 Nov 2026

**What this is.** A map from each planned acceptance group of [ADR 0219](../../adr/0219-discovery-film-enrichment-and-refresh.md) to the executable test that covers it in AIR-605, and an explicit list of what is **not** covered here. All tests run offline on the migrated schema (sqlite3 CLI D1 stand-in) with injected upstreams; none touches production. A listed test is a statement about the code at the PR head, not about production behavior.

| ADR 0219 group | Covered by | Not covered in AIR-605 |
| --- | --- | --- |
| Signal contract: normalized key, coalescing, version token, identical digest wakes nothing, rolled-back change writes none | `migration-0047-catalog-enrichment` sections 2 to 5; `catalog-enrichment-store` (emit) | Emitters that belong to other cards: Discovery (AIR-684), Watchlist (AIR-615), PV1 triggers (AIR-631) |
| Guarded consumption: re-arm during consumption, stale effect, scope, control, lease or identity moved, replay writes nothing | `catalog-enrichment-store` (guarded consumption, reopening kinds, replay) | A merge during a plan beyond the identity guard |
| Wake races: commit then kick, park intent then re-check, kick during handover, lost kick recovered by reconcile, due `retry_at` wakes without cron | `catalog-enrichment-wake` (causal postcommit kick: dormant, runnable, none, failing, rolled back); `catalog-enrichment-workflow` (kick, reconcile, park cancelled by late work, handover successor); `catalog-enrichment-drain` (park until earliest retry, backed-off signal due time) | Platform behavior of `sendEvent` and `waitForEvent` (injected in tests) |
| Scopes and bootstrap | `migration-0047-catalog-enrichment` section 6 and 7 (rated gated by `activated`, scope fence) | Generic rated bootstrap run and fixture (activation and execution are AIR-607); Discovery scope behavior (AIR-684) |
