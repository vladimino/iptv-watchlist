# AIR-374 P3a: EPG producer layer for canonical Film facts, offline tests

**Captured:** 2026-11-12, local runs of `node tests/canonical-epg-producer.mjs`, `node tests/canonical-epg-producer-mutation.mjs`, then the full `npm test -- --jobs 3` and `npm run build`. **Method:** a sqlite file plays D1 (all migrations, schema 19), the same stand-in as the P3-0a and P3-0b tests. No Worker, R2, D1, Cloudflare or network access, and no production measurement (E6 is not done). This file holds counts only: no id, title or payload. Design: [ADR 0124](../../adr/0124-epg-producer-layer-film-facts.md).

**Result:** the pure planning and apply layer for the `film_facts` units of an EPG run exists and is DORMANT: nothing calls it, `build.mjs` is unchanged, `epgSync` is unchanged, no operation is registered and no marker moves. `handoffReadiness` is unchanged: `producer_not_wired:epg_commit` stays a blocker because the producer is not wired and still needs the person kinds. The draft differential exceptions (7 in the registry, 3 of the Film writers) are neither accepted nor edited.
