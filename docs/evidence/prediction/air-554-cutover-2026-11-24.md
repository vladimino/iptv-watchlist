## The defect found in the window and its fix

The first import failed before any batch was sent: the published REST binding renders every `?` of a statement as a placeholder, a string literal of the data included, so a source text containing a question mark failed with `Missing SQL parameter`. The scratch rehearsal of 23 Nov (synthetic text without question marks) and the sqlite stand-in (which renders parameters only when some are bound) could not show it.
